🔗 **Visite o site:** [https://peddroka.github.io/To-Do-List/](https://peddroka.github.io/To-Do-List/)

 📋 To-Do List
To-Do List simples e funcional desenvolvida com HTML, CSS e JavaScript puro. O aplicativo permite adicionar, editar, concluir e remover tarefas, oferecendo uma interface limpa, responsiva e intuitiva.

🎯 Objetivo
Facilitar a organização pessoal e aumentar a produtividade com uma solução leve, prática e eficiente.

🚀 Funcionalidades
Adicionar novas tarefas

Editar tarefas existentes

Marcar tarefas como concluídas

Remover tarefas

Design responsivo

Armazenamento local (localStorage) para manter os dados salvos
